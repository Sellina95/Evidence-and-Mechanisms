Frameworks
This directory contains reusable explanatory frameworks that emerge from completed empirical cases.
Frameworks should not be created in advance simply to build a taxonomy.
A framework belongs here when evidence from one or more cases makes it useful beyond the original investigation.
A Reusable Framework Should Identify
- the proposed mechanism or transmission
- the conditions under which it is expected to hold
- important assumptions
- known failure modes or alternative channels
- supporting cases
- unresolved limitations
Frameworks remain revisable.
A later case may strengthen, narrow, condition, or overturn an earlier framework.
