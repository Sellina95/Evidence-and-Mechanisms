Cases
This directory contains bounded empirical investigations.
Each case begins with a real observation, anomaly, or research question. Cases should not be created merely to populate the repository.
Suggested Naming
CASE-001-short-descriptive-title/
Case Principle
Each case should preserve the path from prior expectation to empirical reassessment:
Observation → Baseline Framework → Observed Deviation → Research Question → Competing Hypotheses → Evidence → Conclusion → Framework Update
A case may close with:
- a supported explanation
- a conditional explanation
- rejected hypotheses
- unresolved competing explanations
- UNKNOWN
Closure does not create an obligation for recurring monitoring, automation, or maintenance.
